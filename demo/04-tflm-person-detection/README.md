# TFLM person detection example

Offline person-detection demo using TensorFlow Lite for Microcontrollers on an ESP32-S3.
The int8 model classifies 96×96 grayscale images into **person** and **no person**.

`AppFeed` exposes the bundled grayscale images (included as C++ headers) one at a time.
`AppInference` loads the `person_detect` model, runs the TFLite Micro interpreter, and logs the winning label with its score.

> **Tip:** use [tools/imgtoh.sh](../../tools/imgtoh.sh) with the `-g` flag to convert an image to a 96×96 grayscale C++ header:
> ```bash
> tools/imgtoh.sh photo.png demo/tflm-person-detection/main/data/my-image.png.h -g
> ```

## Project structure

```
main/
├── main.cpp                      # Entry point — init + inference loop
├── AppFeed.hpp                   # Image source: streams bundled 96x96 grayscale frames
├── AppInference.hpp              # Runs TFLite Micro interpreter and logs top label
├── data/
│   ├── cat-1.png.h               # Grayscale C++ headers generated by tools/imgtoh.sh -g
│   ├── human-1.png.h             # (one per test image)
│   └── …
└── model/
    ├── person_detect_model_data.cc/.h  # Compiled int8 TFLite model
    └── model_settings.cc/.h            # Input dimensions and label constants
```

## Running on Wokwi

Build:

```bash
rm -rf sdkconfig build/ && PRJ_TARGET=wokwi idf.py build
```

Run:

```bash
wokwi-cli . --timeout 120000 --fail-text "Backtrace:" --expect-text "Returned from app_main"
```

## Running on ESP32-S3

Build:

```bash
rm -rf sdkconfig build/ && PRJ_TARGET=esp32s3 idf.py build
```

Run:

```bash
idf.py flash monitor -p /dev/ttyACM0
```
